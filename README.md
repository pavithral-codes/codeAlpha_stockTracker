# CodeAlpha Stock Portfolio Tracker

## About the Project

This is a simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Programming Internship. It calculates the investment value of stocks based on their prices and quantities.

## Features

* Displays predefined stock prices.
* Allows users to enter stock names.
* Accepts the quantity of each stock.
* Calculates the investment value for each stock.
* Displays the total investment amount.
* Handles invalid stock names.

## Technologies Used

* Python

## Stock Prices

* AAPL - $180
* TSLA - $250
* GOOGL - $150

## How to Run

1. Install Python on your computer.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Run the following command in the terminal:

   `python stock_tracker.py`

5. Enter the stock name and quantity.

6. Type `done` to finish and view the total investment.

## Example

```text
Enter stock name (or done): AAPL
Enter quantity: 2
Investment: 360

Enter stock name (or done): TSLA
Enter quantity: 3
Investment: 750

Enter stock name (or done): done
Total investment: 1110
```
